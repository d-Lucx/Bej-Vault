## 🔍 Automated Vault Queries (Dataview)
*(Requires the free **Dataview** community plugin. If you don't have it installed yet, these blocks will sit quietly until you turn it on.)*

### 📥 Recently Modified Notes
```dataview
TABLE file.folder AS "Folder", file.mtime AS "Last Edited"
FROM ""
WHERE file.name != this.file.name
SORT file.mtime DESC
LIMIT 7
```

### 🗂️ Coding & Repo Notes by Tag
```dataview
LIST rows.file.link
FROM #repo
GROUP BY file.etags
```
